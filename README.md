# Matlab 系统辨识 PID 调节仓库

## 项目简介
本仓库用于记录和复现一种基于 Matlab System Identification 的 PID 参数调节方法。

核心思路是：
1. 采集对象输入输出数据；
2. 在 Matlab 中完成系统辨识并获得被控对象模型；
3. 基于辨识模型进行 PID 参数整定与仿真验证；
4. 将参数应用到嵌入式工程中进行实机测试。

## 仓库定位
这是一个面向电机控制场景的实验与工程结合仓库，包含：
- 原始实验数据文件（CSV）；
- Matlab 相关模型与辨识结果文件；
- Simulink PID 仿真模型；
- STM32 工程模板与任务代码，用于实际部署与验证。

## 主要文件说明
- `1.csv`、`2.csv`、`vofa+.csv`：采样数据文件；
- `matlab.mat`：Matlab 数据文件；
- `motor3508.sid`：系统辨识工程或结果文件；
- `pid_model.slx`、`pid_model_double.slx`：PID 仿真模型；
- `Template/`：嵌入式工程模板（STM32 + FreeRTOS 等）。

## 方法流程
1. 数据准备：导入实验采样数据并进行必要预处理（去噪、截取稳态区间等）。
2. 模型辨识：在 Matlab System Identification 中拟合传递函数或状态空间模型。
3. 参数整定：根据模型使用 PID Tuner 或自定义指标进行整定。
4. 仿真验证：在 Simulink 中验证超调量、调节时间、稳态误差等指标。
5. 上板验证：将参数迁移至嵌入式控制程序，进行闭环实测并迭代优化。

## 快速开始
1. 使用 Matlab 打开辨识相关文件，完成模型拟合。
2. 打开 Simulink 模型文件进行 PID 参数仿真。
3. 将最终参数同步到 `Template/` 内对应控制模块并编译下载。
4. 采集新一轮数据，评估并持续迭代。

## 适用说明
- 本仓库适用于课程实验、控制算法验证及电机控制调参流程沉淀。
- 建议在统一采样频率和一致工况下进行辨识，以提高模型可用性。
